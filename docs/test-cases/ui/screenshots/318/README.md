# Fabric calculator: screenshots for issue #318

Taken from a production build with Playwright (Chromium), with the non-secret CI placeholders as configuration and no Supabase. The calculator runs for real in the browser (the nesting worker drafts the seed dress and places the pieces); only the API answers are fixed (the saved version, "no saved calculation", and the save). A temporary page that hosts the calculator was used and not committed. Name: `fabric-calc.<language>.<viewport>.png`; mobile is 390 px wide and desktop 1280 px, full page.
