# Manual test cases

One file per feature: `docs/test-cases/<area>/<issue>-<slug>.md`, copied from `_TEMPLATE.md`.

- Drafted during `/plan`, completed during `/build`, in the same PR as the code.
- Every case says whether it is automated (test file path) or manual only.
- Before a production release, run all `High` cases on staging and fill the "staging" column (`/release-check` lists them).
- `index.md` lists every case with its last result. It is generated by `scripts/test-case-index.sh` and **not committed** (every PR would regenerate it and conflict); run the script to browse it.
