# ADR-188 · 2026-10-18 · Scope every CI check to the files that can change it

**Context:** A docs-only or engine-only PR still ran prettier on the repo, jscpd, depcruise, docs:check, tokens:check and the script tests; `main` re-ran everything after each merge; Turbo had no cache in CI.
**Decision:** (1) `scripts/ci-paths.mjs` gets targets `jscpd`, `depcruise`, `docs`, `tokens`, `scripts` (if-gated steps of the `quality` job, so required check names stay and a skipped step reports success, listed in the job summary). (2) `e2e` ignores engine-only schema files; `docker` ignores `packages/test-fixtures`, engine scripts, `.snap` and `.svg`. (3) `quality` on push to `main` uses the `before..sha` diff; prettier checks changed files only; a nightly run (03:00 UTC) checks everything. (4) `.turbo` is cached with `actions/cache`. (5) The staging deploy keeps running on every merge so `/api/health` `gitSha` equals the merge commit (TC-INF-19-02); skipping docs-only merges needs Merna's decision. (6) The rule table in `docs/WORKFLOW.md` is generated and checked by `docs:check`.
**Reason:** Saves Actions minutes (ADR-86) without losing the safety net: unknown changes run everything, and the nightly run catches scoping mistakes.
**Alternatives:** Turbo remote cache (needs a secret and account decision); a nightly schedule on docker/e2e (docker would push images from the default branch).
