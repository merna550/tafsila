# ADR-86 · 2026-10-11 · Cut GitHub Actions minutes without dropping a check

**Context:** The free private-repo Actions minutes ran out and every job failed in 3 seconds (PR #85). `node scripts/actions-usage.mjs` over the last 30 days (wall-clock, 531 runs, about 1876 minutes): Docker image 1485 (60 runs; the 38 pushes to `main` took about 37 minutes each for the amd64 + arm64 push build, the 22 PR runs about 2 minutes), Dispatch agent 226 (223 runs), Code quality 84, Staging 33, Claude agent 14, other 35. ADR-022 rules out paying.
**Decision:** (1) `scripts/ci-paths.mjs` decides per change whether Storybook (`packages/ui`, root toolchain files, `quality.yml`) and the Docker jobs (`apps/web`, `packages`, root toolchain files, `.dockerignore`, `.github/ci.env`, `docker.yml`; never stories, tests, snapshots, e2e, `.storybook`, Markdown) are needed. A small `scope-*` job runs it and the expensive jobs use a job-level `if`, not `on.paths`, so a skipped job still reports success and a required check can never block a merge. Unknown cases (tags, first push, git error) run the job. The same filter applies to pushes to `main` (compared with the previous commit), which removes most of the 37-minute multi-arch builds. (2) `quality.yml` and `docker.yml` cancel superseded runs of the same PR (`concurrency`, never on `main`). (3) The dispatcher builds only issues labelled `agent:auto`; adding the label also starts it. Without any such issue it starts nothing and its summary says so. All other guards stay. (4) `scripts/actions-usage.mjs` reports usage per workflow.
**Reason:** Docker on `main` and dispatcher builds are the biggest costs; both are avoidable without weakening any check that still runs.
**Alternatives:** `on.paths` filters (a required check would stay "expected" forever and block merges); raising the spending limit, making the repo public, a self-hosted runner (out of scope, Merna decides); dropping arm64 emulation from `main` builds (not decided here, would help most, open for Merna).
