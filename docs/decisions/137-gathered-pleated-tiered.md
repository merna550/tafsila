# ADR-137 · 2026-10-18 · Gathered, knife-pleated and tiered skirts; typed construction marks

**Context:** Issue #137 (FR-PAT-05, FR-VAL-01, FR-VAL-03, FR-VAL-08). Plan: [`docs/plans/137-gathered-pleated-tiered.md`](../plans/137-gathered-pleated-tiered.md). Method: "Gathered, knife-pleated and tiered skirts" in [`drafting-method.md`](../engine/drafting-method.md).
**Decision:**

1. **Typed marks are part of `PatternResult`.** `Piece.marks` (optional) holds `markSchema` items: a stable `id`, a `kind` (`pleat-fold`, `pleat-placement`, `pleat-direction`, `gather`), a shape (`line`, `arrow` from tail to tip, `point`), optional bilingual `text`, optional `edgeId` (the edge whose sewn length the mark changes) and `lengthMm` (the length a gather run is gathered to). The renderer draws them in a new `marks` layer between `darts` and `labels`; fold and arrow lines are solid, placement lines dashed, gathers dotted. Closures (#143) add their kinds to the same enum instead of a second format. Every SVG now has a (possibly empty) `layer-marks` group, so all snapshots were refreshed.
2. **Panel skirts do not start from the straight block.** The block module skips `gathered`, `pleated` and `tiered`; their modules draw rectangles of the finished length with edges `waist`/`top`, `side` (or `seam-left`/`seam-right`), `hem`/`bottom`, `cf`/`cb`.
3. **Intentional ease lives where the seam is.** Tier seams pair `tier-k/bottom` with `tier-(k+1)/top` and declare the gathered extra length as `intendedEaseMm` on both sides, so FR-VAL-01 checks them unchanged. The waist has no partner piece yet (waistbands are #143), so a module rule (`fullnessClosureRule`, FR-VAL-03) reads the waist marks: gather runs count as their `lengthMm`, each pleat arrow folds its own length away, and the sum must be waist + ease within 5 mm.
4. **Ratios.** Gather ratio by fabric weight: light 2, medium 1.8, heavy 1.5; the spec has no fabric weight yet, so medium (1.8) is used. Knife pleats: 16 per skirt, depth 30 mm (intake 60 mm), at least one per panel, spaced half a space, pleat, space, ..., half a space so joined panels stay even. Tiers: 3, each 1.5 × the one above, tier 1 1.5 × the finished waist; heights 30 / 33 / 37 % of the length.
5. **Deterministic, minimal split.** Front and back are cut on the fold while half the widest band plus two side allowances fits the fabric; otherwise the fewest equal panels per half that fit (all tiers use the same count, so tier seams pair panel to panel). Past 8 panels per half the split stops and FR-VAL-08 warns. A centre-back zip makes the back a mirrored pair with a `cb` seam.
6. **`ENGINE_VERSION` 0.6.0 → 0.7.0:** existing gathered, pleated and tiered specs used to get the straight block; every SVG gains the marks layer.

**Consequences:** All three styles draft and validate across the size matrix and fabric widths 600 to 1800 mm. `needs:sew-test` stays: toiles of one tiered and one pleated skirt in 3 sizes are tracked in a follow-up issue and logged in `docs/test-cases/engine/sew-tests.md`.
