## Design analysis (issue #340)

No seed rows: `designs.analysis` and `unsupported_features` are written by the analysis job; tests and the Newman journey create what they need.

## Design photos and AI usage (issue #339)

No seeded photos, `ai_usage` rows or `unsupported_features` rows: photos are private user files and the other two are written by the AI calls. Tests create what they need ([tutorial](tutorials/design-photos.md)).

## Account deletion tests (issue #27)

No seed user is ever deleted. The tests that delete accounts create a throwaway user themselves and remove it, so nothing is seeded for them.

## Seed design hashes (issue #237)

The two `input_hash` values in `supabase/seed.sql` come from `inputHash(spec, measurements, options)` in `packages/engine/src/pipeline/input-hash.ts` with `DEFAULT_ENGINE_OPTIONS` and `sizeLabel: "M"`. To recompute: run a throwaway script with `pnpm exec tsx` from `packages/engine`, importing `seedDress`, the Client M measurements and `inputHash`. The hash is only a dedupe key, so a stale seed hash after an `ENGINE_VERSION` change is harmless.

## Billing (issue #367)

`products` is seeded by the migration (single 49 EGP, pack5 199 EGP, hobby 149 EGP, pro 349 EGP; prices in piastres). `supabase/seed.sql` gives `trial@tafsila.test` a trial grant of 3 credits (no expiry), a 5-credit pack that expires in 90 days and one debit for `Seed dress`, so the balance is 7. `pro@tafsila.test` and `admin@tafsila.test` also got their 3-credit trial through `private.grant_trial` (issue #370; every verified seed account has `trial_granted_at` set), and `pro@tafsila.test` has an active `pro` subscription ending in 5 days (the credits screen shows `renewSoon`). No seeded payments; tests create them. To test the lazy grant, clear `trial_granted_at` of a seed account that has no trial lot (`empty@tafsila.test` after it verifies).

## Design sharing (issue #369)

`pro@tafsila.test` has `share_designs = true` and one design, `Pro shared dress` (the seed dress spec, no photos, no measurements). The other seed users do not share, so the admin list shows exactly that design.
