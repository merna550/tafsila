# Start here

Pick the path that matches you. Each path is an ordered list; the time is an estimate for reading everything on it.

## 1. I am new to programming and web apps (about 90 min)

1. [What is the web, a frontend, a backend, an API?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website) (MDN, 15 min)
2. [What is a database?](https://www.postgresql.org/docs/current/tutorial-concepts.html) (PostgreSQL tutorial concepts, 5 min)
3. [Git in 15 minutes](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F) (Pro Git, 15 min)
4. [The command line](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Command_line) (MDN, 15 min)
5. [Glossary](glossary.md): read the entries for API, endpoint, JSON, package, monorepo, frontend terms (15 min)
6. [map/overview.md](map/overview.md): the system on one page (10 min)
7. [map/repo-tour.md](map/repo-tour.md): what every folder is (15 min)
