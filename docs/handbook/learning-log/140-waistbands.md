title: "Closing a dart by rotation keeps every length, so the traced band always fits"
---

A contour band or waist facing is traced from the skirt's own waist: each part past a dart is turned about the dart's tip until the two legs meet. Turning is rigid, so the traced edge is exactly the waist with the dart mouths left out, the same length the seam-match rule measures. A one-piece band instead splits its sewn edge into one run per cut copy of each skirt piece, so every run pairs with the skirt edge it sews to; anything that is longer on purpose (the closure underlap, gathers, pleats) is declared, never hidden. Elastic is bought by length, so its cut length is typed `notions` data, not a piece.
