title: "Sleeve styles reshape the set-in block and declare what they gather"
---

Every sleeve style starts from the set-in block, so the cap height, the ease and the balance notches stay as the block sets them. The puff keeps the cap below the notches and redraws only the head, solving its rise so it is exactly 1.5 times the old head; the extra length is not hidden but declared, as `gatheredMm` on the cap and as intended ease on the seam, so the sleeve-cap rule still checks the real ease. A cap sleeve or flutter covers only part of the armhole, so it declares the armhole it is not sewn to. A cuff pairs with the hem and declares the gathers between them; which lengths and cuffs each style allows is a table, and anything else is refused with a message instead of drawn wrong.
