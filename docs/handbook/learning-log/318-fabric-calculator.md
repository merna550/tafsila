title: "A third worker for fabric nesting"
---

A third worker for fabric nesting: the page asks the worker for the lengths, the worker drafts the saved version again and places the pieces, and the result is saved on its own. The build check fails if the nesting code ever lands in a page bundle ([decision 318](../../decisions/318-fabric-calculator.md))
