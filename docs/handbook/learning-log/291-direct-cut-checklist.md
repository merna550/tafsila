title: "Direct-cut checklist"
---

The checklist runs the engine's `cutSteps` in the same Web Worker as the preview (a second message type) and one adapter turns its keys and numbers into sentences for the page, so no geometry reaches the main bundle. Ticks live in the browser per version and curve step, and are dropped when the engine version differs, because a changed engine can change the steps.
