title: "The A4 PDF is drawn from the same scene as the viewer"
---

`buildA4Pdf` takes the viewer's scene and draws it on A4 pages at 1:1: a cover with a 10 cm square and the page map, then one page per non-empty tile. One generic builder serves A4 now and A0 later. The file is reproducible: the same input gives the same bytes, so a clock or random call is forbidden by a test.
