---

Ease as data, not scattered numbers: one table of total ease per profile and body line (the SRS numbers), one pure function that subtracts the ease already inside the drafting blocks so it is never added twice, skirt lengths from named shares of the knee-to-floor gap, and a sync test that fails if the engine's copy of the block ease drifts from the reference drafts
