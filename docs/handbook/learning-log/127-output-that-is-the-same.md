Output that is the same byte for byte: SVG built as text with one number formatter (2 decimals, no `-0`), fixed layer and element order, mm units so a print at 100% is 1:1, a scale square to prove it, and snapshots stored as reviewable `.svg` files through a test-only export that keeps vitest out of the app
