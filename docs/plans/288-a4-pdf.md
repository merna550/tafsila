### Approach

All new code is in `packages/export/src/pdf/`, pure (no DOM, no `fetch`, no clock, no random).

1. **Public API** (re-exported from `packages/export/src/index.ts`):
   ```ts
   type PdfMeta = { title: string; versionNo: number; clientLabel: string; engineVersion: string; createdAt: string /* ISO, the version's created_at */ };
   type PdfProgress = (done: number, total: number) => void;
   type PdfBuildOptions = { fonts: PdfFonts; onProgress?: PdfProgress };
   buildA4Pdf(result: PatternResult, scene: PatternScene, meta: PdfMeta, options: PdfBuildOptions): Promise<PdfOutput>
   type PdfOutput = { bytes: Uint8Array; pageCount: number; tileCount: number /* non-empty */ };
   ```
   `scene` is the engine `PatternScene` (#243: `widthMm`, `heightMm`, per-piece `cutD`, `stitchD`, `grainD`, notches, darts, labels). `result` is used only for `meta`-level data the scene lacks; if the scene has everything, drop the parameter later, but keep it now (the issue fixes the signature).
2. **Generic builder** `buildTiledPdf(scene, meta, paper: Paper, options)` in `tiled-pdf.ts` (internal, also exported for #290). `buildA4Pdf` = `buildTiledPdf(..., "A4")` plus the cover page. Steps: `PDFDocument.create({ updateMetadata: false })`; `setCreationDate`/`setModificationDate` = `new Date(meta.createdAt)`; `setProducer("Tafsila")`, `setTitle`; `embedFonts` (#282); `tileSheet(sheetMm, paper)`; cover page (A4 only); one page per non-empty tile; `save({ useObjectStreams: false })`. Deterministic: same input gives identical bytes (tested).
3. **Piece drawer** `draw-pieces.ts`: `drawPiecesInWindow(page, scene, window, frame)` where `frame` = page origin and printable rectangle in pt. It clips to the printable rectangle (`pushOperators(pushGraphicsState(), rectangle(...), clip(), endPath())`, then `popGraphicsState`) and draws, from the scene, at 1:1 with `drawSvgPath(d, { x: originXpt - window.x * MM_TO_PT, y: originYpt + window.y * MM_TO_PT, scale: MM_TO_PT })`: cut line solid, stitch line dashed, grain, notches, darts, labels (`drawLabel`, the Arabic name; piece name and cut text such as "قص ٢"). Line widths and dash lengths are named constants in `style.ts` with reasons (cut 0.6 pt, stitch 0.35 pt dashed 3/2 pt, marks 0.3 pt). #290 calls the same function with an A0 `frame`.
4. **Marks** `draw-marks.ts`: alignment marks (the data from #283, drawn as short ticks at the overlap start on each edge), the dashed cut-line hint inside the overlap strip with the word "overlap/تداخل", the tile label ("B2", bold, large) in the top corner and a small footer: `title - v<N> - engine <ver> - page k/n`. Neighbour hints ("to B3") are not drawn (not in the issue).
5. **Cover page** `draw-cover.ts` (page 1): the 100 x 100 mm test square wrapped in marked content `TestSquare` (`mmToPt(100)` = 283.46 pt) with "measure me: 10 cm / قس هنا: ١٠ سم" below it; design title, version number, client label (omitted when empty), engine version; the page map (tile rectangles at a small scale from #283's map data, label in each, empty tiles crossed out); the print line "Print at 100 % / actual size, do not fit to page" in Arabic and English. Strings live in `strings.ts` (`PDF_STRINGS = { ar, en }`, typed keys, JSDoc); the same wording is added to `docs/design/copy.md` under a new "PDF" heading so there is one source of copy. Digits: Western by default (NFR-06); the label "قص ٢" comes from the engine label text unchanged.
6. **Progress**: `onProgress(done, total)` after the cover and after each tile page; the web worker (#289) forwards it.
7. **Test support** for #289/#290: `src/pdf/test-support/seed-pdf.ts` builds the seed dress M PDF with fonts read from `apps/web/public/fonts` (Node `fs`); `read-pdf.ts` from #282 gains `pageCount(bytes)`, `contentOps(bytes, pageIndex)` (operators as text, numbers rounded to 0.01) for snapshots.

- Unit: determinism, two builds are byte-identical, and `CreationDate` equals `meta.createdAt` (no `Date.now()`; an ESLint-free grep test fails if `Date.now`/`new Date()` without an argument/`Math.random` appear in `src/pdf`).
- Unit: `drawPiecesInWindow` for a tile at a non-zero window draws the piece edge at the expected pt offset (read the first `m` operator and compare to the engine point times `MM_TO_PT`, y flipped); content outside the printable rectangle is clipped (clip operator present before the piece operators).

### Decisions (build writes `docs/decisions/288-pdf-builder.md`)

1. One generic `buildTiledPdf(scene, meta, paper, options)`; `buildA4Pdf` and `buildA0Pdf` (#290) are thin wrappers, so #290 does not "extract" anything later.
2. Fonts and progress are passed in `PdfBuildOptions`; the package does no I/O.
3. PDFs are reproducible: dates come from `meta.createdAt`, fixed font name, no object streams.
4. Page 1 is a cover (test square, map, title block); tiles start at page 2. Empty tiles get no page.
5. PDF strings live in `strings.ts` (ar + en) and are listed in `docs/design/copy.md`.
6. Line widths and dash patterns are named constants in `style.ts`.

### Risks

- Clipping with raw operators is easy to get wrong (state not popped): the unit test reads the stream for balanced `q`/`Q`.
- Many `drawSvgPath` calls on big scenes make the build slow: measure first; if over 10 s on the seed dress, merge paths per layer into one `drawSvgPath` call per piece layer before touching anything else.
- #283 names or shapes differ from this plan: adapt to its merged code; do not change #283's API from here.
- Overlap hint can hide pattern lines: it is drawn thin, grey, under the pieces.
- Page map and labels use Arabic: depends on #282's route; if #282 chose Latin-only labels (fallback d), the map shows Arabic names and tile pages show Latin only, as that decision says.

## Deviations

- `buildTiledPdf(result, scene, meta, paper, options, withCover)` takes `result` too (it runs `tileInput(result)` and finds the sheet's scale square); `PdfOutput` and `PdfBuildOptions` are as planned.
- Extra files: `draw-label.ts` (turned labels, physical left/right alignment), `marked.ts` (tag names so tests can read tile labels and the map back), `purity.test.ts`. The planned `a4-pdf` snapshot lives in `src/pdf/__snapshots__/`.
- The cover uses Western digits ("10 سم"); `read-pdf.ts` gained `pageCount`, `markedTags`, `contentOps`.
- Property test runs 15 sheets (not 50) to stay under the per-test time budget; the PNGs of the visual check come from `pnpm --filter @tafsila/export render:sample` (pdftoppm), not attached to the PR.
- Overlap hint: a dashed grey line along each alignment mark with a cross tick at both ends, plus the word "تداخل / overlap" in the strip; no separate line inside the strip.
