## Plan: #290 A0 copy-shop PDF

Plan wave M4 (PDF family), 2026-10-25. Planned together with #282, #288, #289. Small on purpose: #288 already builds the shared tiled-PDF code (`buildTiledPdf`, `drawPiecesInWindow`, `PdfMeta`, `PdfBuildOptions`), #283 owns the tile layout, #289 owns the worker and dialog. This issue only adds the A0 wrapper, a title block, one worker entry and one dialog row. Depends on #289 (and so #288, #283). Tile names are generic: use the merged names from #283.

### Approach

1. **`packages/export/src/pdf/a0-pdf.ts`**: `buildA0Pdf(result, scene, meta, options: PdfBuildOptions): Promise<PdfOutput>` (same types as `buildA4Pdf`).
   - Sheets come from `tileSheet(sheetMm, "A0")` (#283: no overlap, orientation chosen for fewer sheets). Page size = 841 x 1189 mm in pt (2383.94 x 3370.39, swapped for landscape), from `A0_PT` (#282 `units.ts`).
   - Sheet 1 needs room for the 10 x 10 cm test square (marked content `TestSquare`, same helper as A4) and the title block (title, version, client label, engine version, "measure me: 10 cm", "ask the shop to print at 100 %" in Arabic and English). They must not sit on top of pieces, so the builder reserves a header band: it calls `tileSheet` with `heightMm + A0_HEADER_MM` (constant, 140 mm, named with the reason: 100 mm square + 40 mm margins) and shifts the scene down by that amount (the `frame` passed to `drawPiecesInWindow`). The header is drawn in the top-left of sheet 1 only. This uses #283's API unchanged.
   - Each sheet: pieces via `drawPiecesInWindow` (#288), tile label drawn only when there is more than one sheet, small page-map block in the title block when there are several sheets, and corner marks from #283's mark data (no overlap, so they show where sheets join).
   - Progress via `onProgress`, reproducible output as in #288.
2. **Worker**: in `shared/pattern-export` add `"a0"` to `ExportKind` and one `BUILDERS.a0` entry in `export-handler.ts`; `file-name.ts` already handles `-A0.pdf` (its test gets the A0 case).
3. **Dialog**: append the A0 row to `EXPORT_OPTIONS` (`features/pattern-export/model/export-options.ts`), messages `patternExport.option.a0.label` ("A0 (copy shop)") and `.hint` ("Ask the shop to print at 100 %"; Arabic from the #281 design / copy.md), the instructions block shows the shop note when A0 is selected. `pattern_exported` already accepts `kind: "a0"`.
4. **Strings** for the A0 title block go into `strings.ts` (#288) and the "PDF" section of `docs/design/copy.md`.

### Decisions (build writes `docs/decisions/290-a0-header.md`)

1. A0 reserves a 140 mm header band on sheet 1 for the test square and title block instead of a cover page (a single A0 sheet should stay a single sheet), by adding it to the sheet height passed to `tileSheet`.
2. The A0 builder is a wrapper over #288's generic `buildTiledPdf`; nothing is extracted here because #288 already did it.
3. Tile labels and the page map appear on A0 only when there is more than one sheet.

### Risks

- The 140 mm band can push a pattern from one sheet to two: the seed dress sheet count is pinned in a test and recorded in the PR so a change is visible; if the dress goes from 1 to 2 sheets only because of the band, shorten the margins (not the 100 mm square) and say so in the decision.
- A0 landscape vs. portrait: whatever #283 returns is used; the builder does not decide.
- A copy shop may scale files: the title block and dialog both say "100 %" and the test square lets the user check (#295).
- Large page size makes PDF viewers show thin lines faint: line widths stay the #288 constants; check in #295.

**Size:** S (unchanged). **Build:** `build:sonnet` (unchanged). `needs:sew-test` stays (#295). `needs-interactive`: no.

## Deviations

- The builder is `buildTiledPdf` with a new `withHeader` layout flag (not a separate drawing path); `buildA0Pdf` is the thin wrapper. The header code lives in `packages/export/src/pdf/a0-header.ts` (constants there, not in `style.ts`).
- Cover helpers (`drawTestSquare`, `drawTitleBlock`, `drawPageMap`) were parameterised by position and exported so the A4 cover and the A0 header share them; the A4 snapshots are unchanged.
- The seed dress takes 2 A0 sheets without the band and 3 with it (portrait 2 x 2, one empty). No margin change: the plan only asked for one when 1 became 2.
- The tile label is skipped when an A0 file has one sheet (`drawTileLabelAndFooter` accepts `null`).
- Test cases: TC-ENG-288-08..11 in the A0 section of `docs/test-cases/engine/288-pdf-a4.md`; the UI row is TC-UI-289-10.
